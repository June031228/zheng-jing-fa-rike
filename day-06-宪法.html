一句话核心：宪法是国家的根本法 — 国内法律体系里位阶最高、效力最强、修改最难；合宪性审查是"看守宪法的警察"，任何下位法、行政行为、地方条例都不能违宪。我国不走美国"司法审查"道路，而是人大监督 + 宪法和法律委员会协助 + 法工委日常的"事前审议 + 事中合宪咨询 + 事后备案审查"三段式闭环。

一、专业名词解释

宪法（Constitution / Constitutional Law）：规定国家根本制度、根本任务、公民基本权利义务、国家机构组成与权力运行的根本法，是其他法律的"母法"（Mother Law）。在我国法律体系中位阶最高 — 《宪法》是母法，其他法律（含基本法律、行政法规、地方性法规）都是子法，不能与宪法抵触。口诀：宪法是天花板，下面的规矩都得守它。
根本法（Fundamental Law / Lex Fundamentalis）：法学概念，强调凌驾一切普通法律之上、修改程序最严格、解释和适用优先。我国宪法序言末段明确"具有最高的法律效力"。口诀：改宪法比改法律难得多。
合宪性审查（Constitutional Review）：对法律、法规、规章、行为是否合宪进行的专门审查 — 发现违宪就撤销、纠正、责令改正。世界三模式：美国式（普通法院在案件中审查 — "司法审查"，1803 *Marbury v. Madison*）、德国式（独立"宪法法院"专管，1951 设立）、中国式（人大监督 + 备案审查制 + 专委会协助）。口诀：谁来守宪法，是三模式之间的最大差别。
备案审查（Filing-and-Review）：我国宪法监督的核心抓手 — 行政法规、地方性法规、司法解释等制定后向全国人大常委会备案，发现与宪法法律抵触就撤销、要求修改、提书面审查意见。它是合宪性审查重要的事后路径之一。口诀：备案是"挂号"，审查是"会诊"，撤了就是"开刀"。
宪法和法律委员会（Constitution and Law Committee）：2018-03 十三届全国人大一次会议设立的专门委员会，承担"推进合宪性审查""宪法解释、研究宪法实施"等职责，是全国人大协助宪法监督的"专门工作机构"。口诀：宪法和法律委员会是"宪法看护岗"的常设编制。

二、知识点（连贯主线）

1宪法的"根本法"地位 — 为什么它最牛？国内法律体系是金字塔：宪法（最上）→ 基本法律（民法典/刑法/立法法，全国人大制定）→ 一般法律 → 行政法规（国务院）→ 地方性法规 → 部门/地方规章。《宪法》序言末段自我宣示为"具有最高的法律效力"；《立法法》第 103 条（2023 修正）规定"一切法律、行政法规、地方性法规…都不得同宪法相抵触"；《宪法》第 64 条规定宪法修改须 1/5 提议 + 2/3 通过，相比普通法律只须过半数通过。门槛叠加就是要让改宪法这件事很难发生。口诀：宪法是金字塔的塔尖 — 下位法错位表述 + 行为都得围着它转。
2宪法内容的"四梁八柱"：① 国家根本制度（国体 = 人民民主专政、政体 = 人民代表大会制度、基本经济制度 = 公有制为主体多种所有制共同发展）；② 公民基本权利与义务（平等、政治、人身、社会经济、文化权利、特定主体保护）；③ 国家机构（人大、国务院、国家主席、军委、地方人大与政府、监察委、法院、检察院的产生与职权）；④ 宪法自身运行（修改、监督、解释、宣誓制度）。易踩坑：以为宪法"管不到我"。其实宪法 通过下位法和具体行为在影响你每一顿饭、每一次离职、每一张选票。
3宪法监督的三种世界模式 — 凭什么差别这么大？
模式谁来审典型国家起源标志
司法审查（Judicial Review）普通法院在具体案件中审查美、加、日、印度1803 *Marbury v. Madison*
专门宪法法院（Constitutional Court）独立宪法法院专管违宪争议德、奥、韩、俄德国 1951 设立联邦宪法法院
人大监督 + 备案审查 + 宪法和法律委员会协助全国人大及其常委会主导，专委会协助中国2018 宪法修正案与全国人大组织法
关键差别：在我国 普通法院不能在案件中直接宣告"某部法律违宪无效" — 违宪审查由人大系统做。这与美国"法官一句话废法律"完全不同。
4中国的"事前 + 事中 + 事后"合宪性审查闭环事前：法律草案审议时宪法和法律委员会做合宪前置审查（法律"出生前"的体检）；事中：法律实施过程中人大常委会可就重大涉宪问题提合宪咨询意见；事后：行政法规、地方性法规、司法解释等向全国人大常委会备案，法工委每年向常委会作备案审查工作情况报告。法律支撑：宪法第 62、67 条 + 《立法法》第 103–113 条（2023 修正）+ 《监督法》第 28–31 条 + 2018 宪法修正案。外人看得见的最日常动作：每年 12 月常委会会议上，法工委主任作备案审查工作情况报告 — 许多轰动一时的"地方条例被纠正"故事就是这一刻被记入公共记忆。
5违宪的法律后果 — 撤销、纠正、整改、追责处理工具由轻到重：书面审查意见（提醒自查自纠）→ 限期修改（整改）→ 依法撤销（最严厉，文件直接失效）→ 依法追责（责任人）。例如某省条例规定"女职工怀孕即视为自动离职"被书面要求修改最终删除 — 这是典型的"备案审查 + 合宪"纠正流程。口诀：合宪性审查不是"给法律找茬"，是"给法律做体检"。

三、由浅入深案例

生活场景

你买的车位可不可"只卖不租"？你新搬进小区，物业说"地下车位只售不租、35 万元一位"，打 12345 得到住建部门答复："《民法典》第 276 条规定：建筑区划内，规划用于停放汽车的车位车库，应当首先满足业主的需要"。物业若"只售不租"导致大量业主无处停车 — 违反民法典强制性规定。但是这一条款要不要先"过一遍宪法"？业主的基本财产权（宪法第 13 条）和物业、车位的所有权（民法典）发生冲突时，谁来"称量"？这就是合宪性审查发挥作用的地方：下位法（《民法典》、地方物业管理条例）都必须与宪法对私有财产权的保障相一致。业主的可行路径：先诉讼至法院请求确认决议无效（法院根据民法典裁判），再由法工委通过备案审查纠正地方条例。这是一幅"宪法 → 民法典 → 业主决议"的位阶图。

真实新闻

2023 年法工委备案审查报告 — "女职工怀孕被解雇"等地方性法规被纠正。来源：2023-12-26《全国人民代表大会常务委员会公报》刊载《2023 年备案审查工作情况报告》；新华社、中央广播电视总台、中国妇女报等媒体报道（2023-12-26）；《中国妇女报》"备案审查：保障'她权益'的法治力量"（2023-12）。

① 背景：过去一些地方性法规、规章中存在与上位法、宪法相抵触的条款 — 某省人口与计划生育条例含"已婚妇女违反计划生育政策的，不得在原户籍地落户"等条款，违反《妇女权益保障法》《人口与计划生育法》及宪法上的平等权；一些地方规范性文件在女职工"三期"（孕期、产期、哺乳期）保护、婚姻家庭权益保障上设置不当限制；② 2023 年动作：法工委在备案审查工作报告中明确指出，"已经过初步审查认为与宪法法律不一致的，研究提出书面审查意见，督促有关制定机关予以纠正" — 其中明确点名"有关地方性法规关于妇女权益的个别条款与宪法法律不一致，已督促纠正"；③ 制度意义：这是备案审查机制"说硬话"的典型时刻 — 下位法（地方性法规）被点名纠正，宪法和法律的位阶得到具体维护；④ 可持续机制：任何公民、组织都可向全国人大常委会提出审查建议（除《行政诉讼法》第 64 条诉讼建议之外的另一条"宪法支撑"建议权）。这是普通公民"参与合宪性审查"的关键入口。

知识点对应：合宪性审查的"事后审查"环节（备案审查流程启动）；撤销权与书面审查意见（处理工具的实际使用）；公民、组织备案审查建议权（民众参与机制）；宪法第 33 条：公民在法律面前一律平等（纠正的宪法根据）。结论：宪法通过备案审查"能办事" — 它不是抽象的最高法，而是真能纠正地方条例"不合法 + 不合宪"条款的国家机制。

来源：2023-12-26《全国人大常委会公报》《2023 年备案审查工作情况报告》；新华社、央视、中国妇女报 2023-12 报道。
真实新闻

2018 年宪法宣誓制度入宪、宪法和法律委员会设立 — 宪法地位的两大里程碑。来源：2018-03-11 第十三届全国人民代表大会第一次会议通过《中华人民共和国宪法修正案》；新华社、人民日报、央视新闻（2018-03-11—18）全程报道；《全国人大常委会公报》2018 特刊；《全国人大组织法（修正）》2018-03 同次大会表决。

① 第一件大事：宪法宣誓制度入宪。宪法修正案在第 27 条增加一款："国家工作人员就职时应当依照法律规定公开进行宪法宣誓"。法律落地：2018-05-01 起施行的《全国人大常委会关于实行宪法宣誓制度的决定》；具体仪式：70 字誓词 — "我宣誓：忠于中华人民共和国宪法，维护宪法权威，履行法定职责……"；仪式规格：全国人大、国家机关工作人员、地方各级人大、各级人民政府等任命时举行公开宣誓；制度价值：让宪法从"墙上的纸"变成"嘴边的誓"。

② 第二件大事：宪法和法律委员会设立。宪法修正案在第 70 条规定全国人大设立宪法和法律委员会（替换原"法律委员会"职能，并扩展为合宪性审查专责机构）。职能扩张：在《全国人大组织法》同步修改中明确 — 推动宪法实施、开展宪法解释、推进合宪性审查；与法工委协同：宪法和法律委员会负责"专责"，法工委负责"日常"；制度价值：把"合宪性审查"从"人大常委会有权"变为"有专门工作机构在负责"。

③ 第三件大事：国家监察委员会入宪（宪法第 123、125 条等增加）— 宪法的"反腐败三件套"基础之一，与本课主题相对独立但同属"机构与根本制度"模块。

知识点对应：宪法的根本法地位（修改最难 — 2018 修宪须经 1/5 提议 + 2/3 通过）；合宪性审查的中国模式（人大主导 + 宪法和法律委员会协助）；宪法宣誓对宪法权威的具体化；国家机关组织在宪法中的地位（国家机构章的扩张）。结论：这是"宪法发展史里一段最直观的现代事件" — 三年后的备案审查动作，正是建立在 2018 年这两个机构性安排之上的。

来源：2018-03-11 新华社《十三届全国人大一次会议表决通过宪法修正案》；人民日报、央视新闻同步报道；《全国人大常委会公报》2018 特刊；《全国人大组织法》2018 修正。
制度 / 原理

合宪性审查 vs 司法审查 — 为什么我们不能"在法庭里废法律"。把"三种违宪审查模式"做成一张表，看中国的"事后备案审查 + 事前审议 + 事中合宪咨询"组合：

维度美国式（司法审查）德国式（专门宪法法院）中国式（人大监督 + 备案审查 + 宪法和法律委员会）
谁审最高法院在具体案件中联邦宪法法院全国人大常委会监督，宪法和法律委员会协助，法工委办
模式具体案件附带审查抽象 / 具体审查并行事前 + 事中 + 事后 三段式
标志案例1803 *Marbury v. Madison*；1974 *United States v. Nixon*1951 联邦宪法法院成立；多起宪法诉愿2018 宪法和法律委员会设立；2023 法工委备案审查报告点名纠正
老百姓怎么参与个案中直接起诉提交宪法诉愿任何公民、组织可向全国人大常委会提出审查建议，法工委办理
对抽象立法的审查较弱（要等个案）强（可主动审查）强（备案审查主动巡检）

关键提炼：① 能"废"法律的：法院 OR 宪法法院 OR 人大 — 这是国家权力分配的根本选择；② 普通法院有没有"违宪裁判权"决定"宪法如何在日常被激活" — 美国能、我们不行；③ 中国对规范性文件的系统巡检能力是三种模式里最强的 — 备案审查每年把海量法规、规章、司法解释挨个过一遍；④ 普通公民参与合宪性审查的入口：① 向全国人大常委会提审查建议、② 关注备案审查年度报告、③ 在地方人大常委会的备案审查工作中反映具体问题。

常被混淆的概念：备案审查 ≠ 行政复议 ≠ 行政诉讼。备案审查的对象是规范性文件（法规、规章、司法解释），复议 / 诉讼的对象是具体行政行为；前者维护"法律的位阶"，后者维护"个人的权利"。两者之间是层级错开的，但在实际生活中互相促进。

来源：综合张千帆《宪法学导论》、王磊《宪法的司法化》；2018 宪法修正案全文；2023 备案审查工作情况报告。

五、当日小结

宪法是国家的根本法 — 位阶最高、效力最强、修改最难，规定了国家根本制度、公民基本权利、国家机构与权力运行。合宪性审查是"看守宪法的警察"：在美国由法院在案件中审查（司法审查），在德国由独立宪法法院专管，在中国由全国人大常委会监督、由宪法和法律委员会协助、由法工委做日常 — 形成"事前审议 + 事中合宪咨询 + 事后备案审查"的闭环。备案审查是合宪性审查最日常、最高频的"事后体检"，每年报告会点名纠正"与宪法法律不一致"的法规、规章、司法解释。宪法权威既有制度硬约束（撤销、纠正、整改、追责），也有仪式软加持（宪法宣誓制度）。普通公民的参与入口：向全国人大常委会提出备案审查建议、关注备案审查年度报告、在具体诉讼中"间接激活"宪法原则。本课是律法主线的"宪法根基"一课，下一课会从"宪法地位"下沉到"公民基本权利"。

3. （简答）为什么在我国不能像美国一样让普通法院"在案件中宣告某部法律违宪"？请从"权力分配、审查对象、人大地位"三个角度，用 3–4 句话说明。
答案

1. B（我国合宪性审查是由全国人大常委会行使宪法监督权、由宪法和法律委员会提供专责协助、由法工委日常办理，包含事前审议（法律草案）、事中合宪咨询、事后备案审查三阶段的组合机制。A 错 — 这是美国"司法审查"模式，我国普通法院不能在案件中直接宣告法律违宪无效；C 错 — 国务院没有合宪性审查权；D 错 — 最高人民检察院是法律监督机关（针对刑事案件等），不是合宪性审查主体）

2. C（《立法法》第 103–113 条确立法律位阶与备案审查制度、《各级人民代表大会常务委员会监督法》第 28–31 条规定备案审查的具体程序，二者构成"备案审查"的法律基础。A 错 — 是行政处罚的基本法律；B 错 — 是民法典的基本原则条款；D 错 — 是刑法罪刑法定原则）

3. ① 权力分配不同：我国宪法把最高国家权力交给全国人民代表大会（"一府一委两院"对它负责），而不是交给司法机关 — 这是"议行合一"的人民代表大会制度安排；② 审查对象不同：美国司法审查是对具体案件中适用法律做附带审查，我国备案审查是对抽象规范性文件（法规、规章、司法解释）做主动巡检，两者侧重不同；③ 人大地位不同：我国宪法明确全国人大及其常委会是宪法监督主体，所以违宪审查权在人大 — 普通法院若越权宣告法律违宪，会违反宪法第 62、67 条，所以不能也不必这样做；④ 因此我国更强调事前 + 事中 + 事后的体系化合宪性审查机制，而不是依赖法院的"一句话废法律"。这是中国宪法体制设计的核心特征，不能用美国模板理解中国宪法。
