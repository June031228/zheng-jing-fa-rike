# 政经法零基础日课

政治 / 经济 / 律法，三科轮换，**每天一科**，由 AI 每日自动生成并发布。面向零基础成人自学者，每课含：**连贯知识点 + 专业名词解释 + 由浅入深（真实新闻优先）案例 + 延伸阅读书目章节 + 自测题**。

> 你已熟悉 PMP / IE / 6Sigma 的体系化打法，本系列沿用"模块化、循序渐进"节奏，并针对零基础强制补齐上述四块。
