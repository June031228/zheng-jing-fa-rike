第 5 课 · 经济 · 供需与价格：无形的手如何定价

政经法零基础日课　|　轮换：政治 → 经济 → 律法（每天一科）　|　面向：零基础成人自学
📄 腾讯文档版（手机可读）
本课位置：第 2 轮"经济"开篇 · 回答"商品价格由谁定" · 第 2 课讲稀缺与选择，本课讲供需如何决定价格
一句话核心：价格由需求与供给这一对看不见的力量共同决定 — 二者会在某个数量与价格上自动趋向均衡；当市场被打乱或被认为不公平时，政府才会介入限价或补贴，但限价是双刃剑 — 它屏蔽的是价格信号，治不了供需缺口。

一、专业名词解释

需求（Demand）：在一定时间内、各种可能价格下，消费者愿意且能够购买的商品数量。关键两层：愿意（偏好）+ 能够（钱）。口诀：有心又有力，才算需求。
需求定律（Law of Demand）：其他条件不变时，价格上升 → 需求量下降；价格下降 → 需求量上升。整条曲线向右下方倾斜。口诀：越贵越没人买，越便宜越多人抢。
供给（Supply）：在一定时间内、各种可能价格下，生产者愿意且能够提供的商品数量。同样两层：愿意 + 能够（技术 + 成本 + 产能）。口诀：有人产得起，才算供给。
均衡价格（Equilibrium Price）：需求曲线与供给曲线相交点对应的价格 — 此时想买的人 = 想卖的人，市场出清。口诀：买卖两不亏，价格刚刚好。
价格管制（Price Control）：政府对价格的人为设定，包括最高限价（Price Ceiling，常见于房租、口罩）与最低支持价（Price Floor，常见于粮食最低收购）。口诀：限价是绳子，最多拉到天花板或地板。

二、知识点（连贯主线）

1需求曲线：把"价格 ↔ 需求量"画成一张图。横轴 Q、纵轴 P。点连起来是一条向右下方倾斜的曲线 — 来自替代效应（A 涨价去买 B）和收入效应（商品涨价等于口袋里钱变毛）。人口、收入、季节、流行偏好会让整条曲线平移。口诀：先看曲线斜（量变），再看曲线移（质变）。
2供给曲线：跟需求曲线反着，向上倾斜。原材料、工资、利率上涨 → 整条供给曲线向左上方挪（成本高了）；新工艺、新厂、规模化 → 向右下方挪（更便宜、相同价格能供给更多）；预期涨 → 惜售、预期跌 → 抢出货。名词一字之差：同曲线上下动叫"需求量变"（价格变化导致），曲线整体挪叫"需求变了"（收入、人口、偏好等导致）。
3均衡：两条线一交，市场就"稳"一段时间。价格高于均衡 → 供过于求 → 价格被压下来；价格低于均衡 → 供不应求 → 价格被拉上去；在均衡点 → 想买的人 = 想卖的人，市场出清。记住：均衡价格 ≠ "合理价格"，是"市场自动出清"的那个价格。
4当曲线挪动：猪周期与口罩涨价是怎么来的。曲线整体平移（不是同曲线上下移动）通常来自外部冲击：疫情 → 需求曲线右移（口罩抢购）；非洲猪瘟 → 供给曲线左移（能繁母猪减少）；2019–2020"超级猪周期"就是非洲猪瘟（供给收缩）+ 环保限养（供给进一步收缩）+ 疫情囤肉心理（需求短期上涨）三力齐发。不是价格自己动，而是曲线动了，价格跟着动。
5价格管制：政府的两只手，以及它们的副作用。最高限价（口罩、房租）：短期防暴涨，但生产意愿下降 → 供给减少，继而出现黑市、抢购、配给；最低支持价（粮食最低收购）：保护生产者积极性，但 → 库存积压、财政补贴。判断原则：政府限价 ≠ 解决供需问题，只是把"价格信号"屏蔽了 — 真解决靠产能恢复 + 物流打通 + 必要时补贴生产端。口诀：限价格不治根，补生产端才治本。第 8 课"市场与失灵"会再展开。

三、由浅入深案例

生活场景

一杯柠檬水的"市场价格"是怎么形成的。周末小区门口摆摊，7 元没人、5 元刚好、3 元抢光。你和隔壁大叔同样卖柠檬水 — 但他大批进货、成本更低，供给曲线位置不一样。突然小区办市集涌入 500 游客 → 你的需求曲线整体右移；市集结束 → 又整体左移。如果你想"薄利多销"降到 4 元 — 同一需求曲线从 A 到 B，是"需求量变"；如果你换口味做百香果柠檬水 — 是"需求曲线整体右移"。同样都"卖得更好"，但经济学含义不同。结论：均衡价格不是"应该卖多少"，而是"那一刻市场愿意接受多少"。把它放大到全国猪肉市场、口罩市场，就是本课的全部故事。

真实新闻

2019–2020 "超级猪周期"——猪肉从十几块涨到三十多。来源：农业农村部官网新闻发布（2019-08、2019-11）；新华社《猪价高位运行 农业农村部回应》（2019-11）；央视财经《生猪生产恢复》系列报道（2020）；国家统计局月度 CPI（公开）。

① 冲击：2018 下半年起非洲猪瘟多地出现，集中扑杀 + 环保限养收紧，生猪与能繁母猪存栏大幅下降（农业农村部数据：截至 2019-10，能繁母猪存栏同比降 37%+）；② 反应：猪肉从十几元一斤 → 2019 下半年飙到三十多元，部分省份更高，CPI 中猪肉同比涨幅一度突破 100%；③ 应对：投放储备冻肉（短期供给）、给规模化养殖用地信贷保险支持（中期供给）、严查哄抬价串通价（维护秩序）— 注意：普通猪肉零售价是市场调节价，政府没直接限价，而是从生产端恢复产能；④ 结果：2020 下半年起随产能恢复价格逐步回落，2021 年底回到十几至二十多元。

知识点对应：供给曲线左移（存栏减 → 同价能卖的少 → 均衡价格上升）；替代效应（猪肉贵 → 改买鸡 / 牛 / 蛋）；产能恢复周期（能繁母猪补栏到商品猪出栏 10–14 个月，解释为何高位持续）；政府工具（储备投放 + 补贴养殖 + 行政查处 = 组合拳，不靠"压标价"）。读懂再看 2022 年起又一轮猪周期，道理相同。

来源：农业农村部公开新闻发布（2019-08、2019-11、2020-08）；新华社《猪价高位运行 农业农村部回应》（2019-11）；央视财经《生猪生产恢复》系列报道（2020）；国家统计局月度 CPI（公开）。
真实新闻

2020 疫情初期"口罩涨价"——一次典型"限价 + 哄抬查处"案例。来源：国家市场监督管理总局公开案件通报（2020-01–02）；新华社《市场监管总局严查哄抬口罩价格》（2020-01-25、2020-02）；央视财经系列报道；各地市场监管局公告（公开）。

① 冲击：2020-01 新冠疫情突发，口罩从"日常用品"瞬间变"防疫刚需"，需求曲线整体大幅右移；② 反应：普通医用外科口罩从约 0.5 元/只涨到 3 元甚至更高，部分电商 5–10 元/只；③ 应对：多地启动价格临时干预（最高限价）；严查哄抬物价（依《价格法》《突发事件应对法》等查处一批典型案件）；打击制假售假；补贴 + 协调转产（中石化、比亚迪、五菱、广汽等"跨界"造口罩 — 让供给曲线短期内整体右移）；④ 结果：跨界产能 2 月底到位，口罩价格自然回落。

知识点对应：需求曲线右移（同价想买的人多了 → 短期均衡价格上升）；限价的副作用（单纯压标价 → 生产意愿打 → 短期供给更紧 → 黑市、"关系单"）；真正化解是供给曲线整体右移（产能 + 原料 + 补贴 + 转产），价格自然回到新均衡；常见疑问"为啥不限到 0.3 元？" — 限得越低、生产者越不愿生产，市场反而买不到。限价是工具不是目标，须配合供给侧政策。

来源：国家市场监督管理总局公开案件通报（2020-01–02）；新华社《市场监管总局严查哄抬口罩价格》（2020-01-25、2020-02）；央视财经系列报道；各地市场监管局公告（公开）。
制度 / 原理

限价的"逻辑陷阱"——为什么经济学家反复劝政府"慎用限价"。把三类价格管制对照：

价格管制工具适用情形短期效果长期副作用
最高限价口罩 / 房租 / 突发灾害防止短期暴涨引发恐慌生产意愿下降 → 供给减少 → 黑市 / 抢购 / 配给
最低支持价粮食最低收购 / 农产品目标价保护生产者积极性库存积压 / 财政补贴压力
不直接限价，补贴生产端想既防暴涨也不打垮供给短期供给增加、长期价格回落财政补贴压力，需评估持续性与公平性

关键提示：① 价格只是信号 — 价格高在告诉"产能不够，请增加供给"，价格低在告诉"产能太多，请减少"。限价 = 关掉这个信号，供需矛盾还在；② 限价是"止痛药"，要尽快配套供给侧政策（补贴、产能、物流）；③ 政策顺序：紧急限价 / 查处 → 投放储备 / 打击囤积 → 补贴生产端 → 让价格回到新均衡；④ 对老百姓的意义：当某样东西突然变贵，不要只看"商家黑心"，同时问一句"是不是供给出问题了？" — 会让你想得开、买不贵。

来源：综合《价格法》《突发事件应对法》及国家市场监督管理总局公开文件；曼昆《经济学原理·微观》第 6 章（公开内容）。

五、当日小结

需求 = 愿意且能买，供给 = 愿意且能卖；二者曲线分别"右下倾斜"与"右上倾斜"，交点就是均衡价格。当外部冲击（疫情、瘟疫、政策）让需求曲线右移或供给曲线左移，均衡价格随之移动 — 这就是"看不见的手"在外部力量下的表现。当价格被认为不合理，政府可介入最高限价或最低支持价，但限价只是"屏蔽价格信号"，治不了供需缺口。真正长期解决短期暴涨的办法是扩大供给（补贴生产、转产协调、产能恢复），让曲线自己回到新均衡。本课是经济主线的"骨架级"一课，后面第 8、11、14、17 课会反复回到"曲线 + 政府"这一基础框架。

六、自测题

1. 关于"需求定律"，下列说法正确的是？　A. 价格上升 → 需求量上升　B. 价格上升 → 需求量下降　C. 价格上升 → 需求曲线整体右移　D. 价格上升 → 供给曲线整体左移
2. 一场突发公共卫生事件让"口罩"需求增加（需求曲线整体右移），其他条件不变，下列推论正确的是？　A. 均衡价格上升、均衡数量上升　B. 均衡价格上升、均衡数量下降　C. 均衡价格下降、均衡数量下降　D. 均衡价格不变、均衡数量上升
3. （简答）为什么单纯"限价到 1 元/只"不能长期稳定口罩供应？请从"价格信号 + 生产者意愿 + 黑市反应"三个角度，用 3–4 句话说明。
答案

1. B（需求定律：其他条件不变时，商品价格上升 → 需求量下降，曲线向右下方倾斜。A 与定律相反；C 错 — 价格变化只让"需求量"沿曲线变化，不会让"需求"整条曲线挪动；D 错 — 价格变化影响的是同一条曲线，不影响供给曲线本身位置）

2. A（需求曲线整体右移，供给曲线不变，新均衡出现在原均衡点右上方 — 价格上升、数量也增加。B 错 — 那是供给曲线左移的情况；C 错 — 那是双重收缩；D 错 — 只要曲线移动、均衡价格必然变化，"价格不变"只在曲线不动时才成立）

3. ① 价格是信号：1 元/只低于市场均衡价，生产者接收的信号是"这种商品不值钱、我不该扩产"，结果产能上不来、供给曲线甚至左移；② 生产端撤退：补贴不足以覆盖成本时，产能退出；③ 黑市反应：消费者愿为"能买到的口罩"付更高价 → 关系单、加价单、灰色市场，反而扰乱市场秩序；④ 正确路径：限价只是"止痛药"，要配合补贴生产端、转产协调、储备投放，让供给曲线整体右移，价格才会回到合理区间。限价屏蔽了价格信号，没解决供需缺口。
